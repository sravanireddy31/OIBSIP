# NovaTech — Digital Solutions

A polished, responsive technology-company landing page created for Oasis Infobyte Web Development & Designing Internship, Level 1 — Task 1.

## Features

- Sticky navigation with smooth section scrolling
- Responsive hero, About, Services, Contact, and footer sections
- Three focused service cards: Web Development, UI/UX Design, and Digital Solutions
- Accessible semantic HTML, keyboard skip link, readable contrast, and responsive layouts
- Custom CSS illustrations and inline visual elements — no image assets or dependencies required
- Mobile, tablet, and desktop styles using CSS Grid, Flexbox, and media queries

## Technologies

- HTML5
- CSS3
- Google Fonts (DM Sans and Space Grotesk)

## Run locally

1. Open the `OIBSIP` folder in VS Code.
2. Open `WebDev-L1-LandingPage/index.html`.
3. Use the **Live Server** extension's **Go Live** button, or open `index.html` directly in a modern browser.
4. Test the navigation links, CTA buttons, mail link, and responsive layout using browser DevTools device emulation.
