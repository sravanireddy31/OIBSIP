# Sravani Gorre — Personal Portfolio

A responsive, static developer portfolio created for Oasis Infobyte Web Development & Designing Internship — Level 1, Task 2.

## Overview

The site introduces Sravani Gorre, a 2025 B.Tech ECE graduate and full-stack developer. It presents education and internship background, technical capabilities, selected projects, and direct contact channels in a professional, accessible layout.

## Features

- Sticky navigation and smooth scrolling between every main section
- Responsive hero with GitHub and contact calls to action
- About, education, six-month internship, and professional-interest details
- Organized front-end, back-end, and data/workflow skills
- Two project cards for Samskruti Stories and the GenAI Image Generation Platform
- Direct email, GitHub, and LinkedIn links
- Accessible semantic landmarks, keyboard skip link, responsive Grid/Flexbox layouts, and hover states
- Light glassmorphism surfaces with a no-blur fallback and reduced-motion support
- No frameworks, build tooling, backend, database, or local image dependencies

## Technologies

- HTML5
- CSS3
- Google Fonts: Manrope and DM Mono

## Run locally

1. Open the `OIBSIP` folder in VS Code.
2. Open `WebDev-L1-Portfolio/index.html`.
3. Start it with the Live Server extension’s **Go Live** action, or open the file directly in a current browser.
4. Test all section links, external profile links, the email link, and responsive breakpoints in browser DevTools.
